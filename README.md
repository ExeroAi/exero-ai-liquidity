# Exero AI

Exero AI monitors every new pump.fun launch, performs in-depth AI-powered audits, and automatically identifies opportunities that match user-defined criteria.

## Features

- Real-time launch monitoring
- AI-powered token auditing
- Risk scoring engine
- Wallet intelligence
- Smart filtering
- Automated execution framework
- REST API
- Dashboard ready

## Architecture

```text
Pump.fun Stream
        │
        ▼
 Token Monitor
        │
        ▼
 AI Audit Engine
        │
        ▼
 Risk Scoring
        │
        ▼
 User Filters
        │
        ▼
 Execution Engine
```

## Installation

```bash
git clone https://github.com/yourname/exero-ai.git

cd exero-ai

npm install
```

## Run

```bash
npm run dev
```
